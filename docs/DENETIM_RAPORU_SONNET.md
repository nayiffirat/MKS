# MKS (Mühendis Kayıt Sistemi) v8.2.1 — Denetim Raporu (Sonnet Denetçi)

- **Kapsam:** `D:\MKS` (React 18 + Vite 5 + Capacitor 6). **Hiçbir kaynak dosya değiştirilmedi** (yalnız bu rapor yazıldı).
- **Yöntem:** Kod okuma + `npx tsc --noEmit` + GS1 ayrıştırıcıyı (`utils/gs1Parser.ts`) esbuild ile paketleyip gerçek karekod örnekleriyle çalıştırma (sonuçlar Bölüm 5). Rapordaki her madde kodda doğrulanmıştır; cihazda/çalışma zamanında doğrulanması gerekenler **(cihazda doğrula)** ile işaretlidir.
- **Ekip:** BKTS/GTS/B-Reçete, Cari, Sync ve tüm "Diğer" bulguların bir kısmı doğrudan `sonnet-denetci`; UI/UX bulguları `ui-denetci` (UI-xx), Stok/EDM/Kasa/Sync bulguları `akis-denetci` (AK-xx), WhatsApp/İzin bulguları `wa-izin-denetci` (WA-xx) tarafından, aynı kuralla (yalnız doğrulanmış) üretilmiş, ben tarafımdan örneklemeyle tekrar doğrulanmış ve rapora birleştirilmiştir.
- **Önem:** KRİTİK = veri kaybı / yanlış resmi kayıt / sahte başarı; YÜKSEK = ana akışta yanlış sonuç veya kullanılamazlık; ORTA = sınırlı senaryoda hata / kalite; DÜŞÜK = kozmetik / hijyen.
- **Ürün önceliği (sıralama bu önceliğe göre yapılmıştır):** 1) Çiftçi cari (+yıllık devir, parçalı tahsilat) → 2) Depo/stok (onaylı sayım) → 3) BKTS/GTS/B-Reçete → 4) EDM e-Fatura & Kasa.
